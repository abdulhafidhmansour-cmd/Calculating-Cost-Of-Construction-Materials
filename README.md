# Cost of construction materials

## Description
A beginner civil engineering project that shows how to use excel with python to calculate cost of constructicn materials.

## Tools used
- Python
- Pandas
- Excel
- Vs Code

## How it works
The project stores construction materials quantities and unit prices in Excel file.Python uses Pandas to read the excel file.It then calculates the quantity of material by the unit price then after getting results creating a new excel file with the results.

## Formula
Total Cost = Quantity x Unit Price

## Project purpose
This project shows how python and excel can work together to automate a simple construction materials cost calculation
